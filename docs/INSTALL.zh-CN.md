# 痛苦小猪 · 熟人试用版安装说明

版本 0.1.0。请先确认安装包来自你信任的发送者，系统和芯片对应正确。

## Windows
1. 下载 PainPig-Windows-x64 构建产物并解压。
2. 双击其中的 Setup.exe 安装到当前用户目录。
3. 小猪出现后可以拖动，右键打开菜单；托盘图标可找回隐藏的小猪。
4. 本测试包未签名，Windows 可能显示“未知发布者”或 SmartScreen 提示。如果安全策略阻止安装，请停止并记录提示，交给项目维护者处理。不要关闭安全软件或更改企业策略。
5. 系统“设置 → 应用 → 已安装的应用 → PainPig”可以卸载。

## Mac
1. “关于本机”中显示 Apple M 系列芯片的，选择 AppleSilicon；显示 Intel 的，选择 Intel。
2. 打开 DMG，把 PainPig 拖到 Applications（应用程序），再从应用程序打开。
3. 小猪图标会出现在顶部菜单栏；点它可以找回隐藏的小猪。
4. 本测试包仅做 ad-hoc 签名，未做 Developer ID 签名和 Apple 公证，系统可能阻止打开。确认来源并尝试打开一次后，如果“系统设置 → 隐私与安全性”提供针对 PainPig 的“仍要打开”，可按系统提示操作。如果没有该入口、显示文件损坏、签名无效或受公司策略限制，请停止并记录提示，交给维护者处理。不要禁用 Gatekeeper 或执行清除隔离属性的命令。
5. 先从菜单栏选择“让小猪下班（退出）”，再把应用移到废纸篓即可卸载。

## 小猪的安排
首次启动所有提醒和登录启动均关闭，保持静音。
右键小猪 → 设置与轻提醒，可自行开启喝水、休息、下班提醒。
默认提醒日是周一至周五，喝水和休息时段是 09:00–18:00；默认间隔为 60 / 90 分钟，下班为 18:00，均可修改。
隐身、锁屏、休眠时暂停。关闭或退出应用期间不提醒。全屏应用和屏幕共享时的展示行为请先试用确认；可随时从菜单隐藏。
本程序不自动识别会议，也不保证从屏幕共享中排除自己。

## 数据
无需登录。全部设置仅保存在本机：
- Windows：%APPDATA%/PainPig/settings.json
- macOS：~/Library/Application Support/PainPig/settings.json

卸载后如想清除偏好，请先退出小猪，再删除对应 PainPig 设置文件夹。应用不会保存情绪原文或读取聊天内容。

人工安装、真实多屏拖动、透明区域穿透和两小时资源占用，需要按仓库 docs/QA.zh-CN.md 完成；没有实测记录时视为待验证。
