# 安装和桌面人工验收

以下均为待执行项目，不能因 CI 成功而自动标记通过。

记录模板：日期 / 提交 SHA / 系统版本与芯片 / 步骤 / 结果 / 截图或错误原文。

## 三个平台分别验证
- Windows 11 x64，Mac Apple Silicon，Mac Intel：从收到的压缩包开始，实际完成安装、首次打开、退出、再次打开和卸载；记录安全提示。
- 首次启动只出现一只小猪，重复打开程序仍只有一只。提醒、登录启动默认关闭。
- 四种形态都能切换并保存；每个小剧场结束后恢复所选形态；戳一戳不会重复弹窗。
- 拖动准确，透明空白处可操作后方应用；拖出边界后仍能找回。多显示器、负坐标、缩放比例和拔掉外接屏分别验证。
- 右键菜单、鼠标靠近的快捷按钮、隐身、托盘恢复、取消置顶、退出均可用。
- 在文本编辑器持续输入时触发提醒：小猪举牌八秒，键盘焦点保持原处；点提醒播放相应动作，忽略后自行消失。
- 同时到期的提醒合并；小剧场期间到期的提醒跳过；关闭单项后不再提醒。
- 在开启喝水提醒后锁屏、休眠、隐身，确认暂停且恢复后不补弹。跨日、改本机时区、调整本机时间不会出现提醒风暴。
- 修改日期、时段、间隔后保存；重开应用仍保留。工作日 18:00 的下班提醒在结束边界触发一次，过点启动不补发。
- 开启和关闭登录启动：退出并重新登录系统验证，卸载前关闭登录启动。
- 断网运行，所有动作和设置可用。没有通知、麦克风、屏幕录制或通讯录权限请求。
- 连续运行两小时：记录静置、演动画、隐藏时的 CPU / 内存，观察是否持续增长。隐藏后应停止动画。
- 检查系统全屏、虚拟桌面、菜单栏深色/浅色模式、会议屏幕共享中的展示；这版提供手动隐藏，不自动检测会议。
