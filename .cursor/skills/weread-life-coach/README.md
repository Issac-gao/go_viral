# 微信读书人生教练

把微信读书的导读，变成针对**你这个人**的生活/职场建议。档案在 `memory/`，会越聊越准。

## 你怎么用

直接说书名，或补一句处境：

```text
我在读《怪诞行为学》第三章。
岗位：____，带不带人：____。
眼前这件事：____。
按人生教练 skill 给导读 + 今天能做的 1 件事。
```

只丢书名也可以。档案空的时候，教练最多问 1–2 句，但仍会给一份标了「推断」的初稿。

## 档案怎么变准

纠正即可，例如：「我不是管理者，是销售。」教练应改 `memory/profile.md`。

不要把公司机密写进档案。雷区写「不能对外说」即可。
