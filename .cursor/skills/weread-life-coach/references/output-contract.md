# 输出契约

## 导读 / 总结（默认）

```text
【书】一句话主题
【书】地图
【书】分章：实验 → 结论 → 细读盯什么
【书】细读抓手
【对你】一小段：一条规律 × 一件真事（+ 可选 1 个动作 / 1 条标题）
```

篇幅：个人部分不超过全文约 15%。档案只在后台使用。

结尾写法：

- 差：每一章都写「书中规律 → 你的网球 → 怎么办」，再加 3 条口播。
- 好：正文讲完相对论和锚定后，结尾一句：「你球场上盯步伐最花的人、用大厂节奏量新公司，就是第 1–2 章的相对比较和旧锚。下场只跟自己上周正手比。」

## 自媒体

仅当用户说要发、要选题、要开头时，在「对你」里加 **1 条**（标题 + 3 句开头）。不要默认给多条。

## 决策咨询 / 复盘

用户在问具体决定或复盘时，可以少讲书、多讲事。这不是默认导读。

## 禁止

- 导读正文用「你」贯穿每一章
- 默认输出今天1 / 本周3 / 不要做2 / 多条口播
- 把用户没说的痛苦写成定论
- 超过 1 页的金句堆砌
