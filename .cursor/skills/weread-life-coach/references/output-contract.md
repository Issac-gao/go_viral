# 输出契约

## 导读 / 总结（默认）

```text
处境一句
书的粗读（主题 + 地图）
细读对照（规律 → 你生活里的那件事 → 启发 → 怎么办）× 3～7
自媒体素材 × 2～3（标题 + 开头3句 + 结尾提问）
行动单：今天1 / 本周3 / 不要做2
细读抓手
档案更新
```

对照条写实，必须点名档案里的真事：

- 差：你要避免非理性消费。 / 学习要注重长期主义。
- 好：你学网球时天天练新步伐却不进步，和书里「为眼前新鲜感放弃基本功」是同一件事；下场训练先只打 50 个正手，新步伐请假一周。
- 好：你若再看到「原价 12800 今日 3980」，先问中间档是不是诱饵；24 小时内不付款。

## 自媒体素材

默认平台按档案；未定时按短视频/图文都能用的口播稿。

每条必须：

- 来自隐喻库真事，不编造没发生的情节
- 大厂、现公司、老板、同事可脱敏（「上一份互联网大厂」「现在的健身品牌」）
- 结构：冲突开头（天天练却没进步）→ 书里的一个词 → 他悟到的一句人话 → 观众能照做的 1 步
- 结尾是提问，方便评论区互动

## 决策咨询

先复述他要选的 A/B 和约束，再用书里 **一条** 主规律下判断，给出：

- 建议选哪个（或现在不选）
- 可发送的原话 / 提纲
- 若判断依赖未知信息：只问 1–2 个问题，同时给「若是 X 就选 A」的条件建议

## 复盘

只点评用户描述的那件事：哪条规律应验、下一步改哪一个动作。不新开一本书。

## 禁止

- 超过 1 页的名人金句堆砌
- 没有截止日期的待办
- 同时布置超过 5 件新习惯
- 把用户没说的痛苦写成定论
