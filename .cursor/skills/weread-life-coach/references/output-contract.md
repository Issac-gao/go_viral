# 输出契约

## 导读 / 总结（默认）

```text
处境一句
书的粗读（主题 + 地图）
细读对照（规律 → 你的场景 → 怎么办）× 3～7
行动单：今天1 / 本周3 / 不要做2
细读抓手
档案更新
```

对照条写实：

- 差：你要避免非理性消费。
- 好：你若再看到「原价 12800 今日 3980」，先问中间档是不是诱饵；24 小时内不付款。

## 决策咨询

先复述他要选的 A/B 和约束，再用书里 **一条** 主规律下判断，给出：

- 建议选哪个（或现在不选）
- 可发送的原话 / 提纲
- 若判断依赖未知信息：只问 1–2 个问题，同时给「若是 X 就选 A」的条件建议

## 复盘

只点评用户描述的那件事：哪条规律应验、下一步改哪一个动作。不新开一本书。

## 禁止

- 超过 1 页的名人金句堆砌
- 没有截止日期的待办
- 同时布置超过 5 件新习惯
- 把用户没说的痛苦写成定论
