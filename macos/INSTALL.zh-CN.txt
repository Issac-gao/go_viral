小猪替你顶一会儿 · Mac 轻量候选版 0.2.0

此版本使用 macOS 自带的 WebKit，不携带 Electron 浏览器运行时。
支持 macOS 13 及以上。M 系列芯片选择 arm64；Intel 芯片选择 x86_64。

安装：
1. 先从菜单栏退出原来的 PainPig，避免同时运行两个版本。
2. 打开 DMG，把 PainPig 拖进 Applications（应用程序）。
3. 从应用程序中打开 PainPig；右键小猪可换形态、演小剧场、设置、隐藏或退出。
4. 隐藏后从 Mac 菜单栏的小猪菜单选择“叫小猪回来”。

原有的四种小猪、轻提醒和本地设置保留。
提醒、登录启动默认关闭；设置只保存到这台电脑。
提醒在隐身、锁屏和休眠时暂停，不补发。
登录启动使用 macOS 的“登录项”；可能需要在系统设置里批准。

签名与首次打开：
这是尚未完成 Developer ID 签名和 Apple 公证的测试版，只有 ad-hoc 签名。
签名完整性检查通过，也不代表 Gatekeeper 会允许从网上下载的应用直接打开。
请查看同包的 SECURITY-REPORT.json，区分：
- DMG 完整性检查；
- 应用代码签名完整性；
- Gatekeeper 分发评估；
- 是否已经开发者签名并公证（本候选版没有）。

如果提示“已损坏，无法打开”，不要将它简单理解为下载损坏，也不要关闭 Gatekeeper。
确认来源后，如果系统“设置 → 隐私与安全性”提供针对 PainPig 的“仍要打开”，可以按系统提示打开。
如果没有该入口，请停止并记录提示，等待正式签名、公证后的分发版本。
本包不附关闭全局安全检查或清除隔离属性的脚本。

构建检查不等同于在你的 Mac 上从浏览器下载后的 Finder 首次打开实测。
鼠标穿透、多显示器、锁屏恢复和持续资源占用仍需真实设备验收。
