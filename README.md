# go_viral

本仓库用于沉淀竞品监测系统的产品、数据与技术实现。

## 竞品监测系统

当前方案聚焦美团、大众点评等本地生活平台上的竞品门店与商品监测，包括：

- 竞品地理位置、行政区、商圈、门店状态。
- 上架商品 SKU、价格、促销、上下架变化。
- 平台展示销量、评价增量、榜单等销量信号。
- 商圈竞品密度、价格带、热卖品类与变化告警。

详细方案见：

- [竞品监测系统方案](docs/competitor-monitoring-system.md)

## 合规原则

系统只应接入合法、授权、可审计的数据来源，例如平台官方或合作 API、合法第三方数据服务、企业自有授权导出、人工调研数据等。

不应绕过平台登录、验证码、签名、加密、限流、反爬、风控或访问控制，也不应采集消费者个人身份信息。
